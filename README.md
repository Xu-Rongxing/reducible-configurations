# Reducible configurations — interactive diagrams

A step-by-step companion to the 31 reducible configurations in the manuscript dated 17 October 2026. The diagrams display the remaining list-size bounds and coloring demands after each move, together with the corresponding legality calculations.

Select a Claim and a case, then use **Next**, **Previous**, or **Reset**. The arrow keys move through the sequence, **Home** returns to the initial state, and **End** shows the last state. The complete sequence is shown below the diagram. Parameters are displayed symbolically.

These diagrams supplement the mathematical proofs and do not replace them. This repository contains only the static diagram website and its necessary assets.
